# Certificate modal viewer

Certificate thumbnails now open an in-page modal instead of navigating to the raw image.

Features:
- Large centered image preview with dimmed, blurred backdrop
- Certificate title, category, and position counter
- Previous / next controls
- Keyboard left/right navigation and Escape to close (native dialog behavior)
- Click outside the modal to close
- Responsive sizing for phones and desktops
- Original image link remains available from inside the modal

No certificate image files or content records were replaced.
